# Monero Web Wallet (XMR)

A secure, client-side, non-custodial **Monero web wallet** built with React. This open-source browser wallet allows you to send, receive, and manage your **XMR coins** safely and privately without intermediate servers.

## Key Features
* **100% Non-Custodial:** Your private keys never leave your browser.
* **Client-Side Security:** All cryptographic operations are performed locally.
* **React Powered:** Fast, responsive, and modern user interface.
* **Privacy Focused:** Standard Monero security practices to protect your financial data.
